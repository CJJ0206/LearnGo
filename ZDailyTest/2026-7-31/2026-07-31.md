## 一、模块系统

**1.** 在 Go 项目根目录执行 `go mod init learn` 的核心作用是什么？

## 三、字符串

**6.** 以下代码能否编译通过？为什么？

```go
var s string = "hello"
s[0] = 'H'
```

<details><summary>答案</summary>

不能。Go 中字符串是不可变的，不允许通过索引修改单个字符。

</details>

---

**7.** 反引号字符串（raw string literal）和双引号字符串的区别是什么？

<details><summary>答案</summary>

反引号字符串：不处理转义字符，可以跨多行，保留换行符。双引号字符串：处理转义序列（`\n` = 换行）。

</details>

---

**8.** 以下字符串拼接为什么会编译失败？如何修复？

```go
s := "hello"
+ "world"
```

<details><summary>答案</summary>

Go 自动分号插入机制会在第一行末尾加 `;`，导致语法错误。修复：把 `+` 放在行尾：

```go
s := "hello" +
    "world"
```

</details>

## 四、类型转换

**9.** 用 `strconv` 将整数 `42` 转为字符串，写出三种方法。

<details><summary>答案</summary>

```go
s1 := fmt.Sprintf("%d", 42)
s2 := strconv.Itoa(42)
s3 := strconv.FormatInt(int64(42), 10)
```

</details>

---

**10.** `strconv.ParseInt("123", 10, 64)` 的三个参数分别代表什么？返回值类型是什么？

<details><summary>答案</summary>

- 参数1：要解析的字符串
- 参数2：进制（10 = 十进制）
- 参数3：`bitSize`，限制结果范围（不改变返回类型，仍为 `int64`）

返回 `(int64, error)`。

</details>

---

**11.** `strconv.ParseInt("hello", 10, 64)` 会 panic 吗？返回什么？

<details><summary>答案</summary>

不会 panic。返回零值 `0` 和一个非 nil 的 `error`。用 `_` 忽略 error 时只得到 `0`。

</details>

## 五、运算符

**12.** 以下两行输出分别是什么？解释原因。

```go
fmt.Println(10 / 4)
fmt.Println(10 / 4.0)
```

<details><summary>答案</summary>

- `10 / 4` → `2`（整数除法截断）
- `10 / 4.0` → `2.5`（4.0 为浮点字面量，触发浮点运算）

</details>

---

**13.** `-10 % 3` 的结果是多少？用公式说明。

<details><summary>答案</summary>

`-1`。公式：`a % b = a - (a/b)*b`，即 `-10 - (-10/3)*3 = -10 - (-3)*3 = -10 + 9 = -1`。

</details>

---

**14.** Go 中 `i++` 和 `++i` 哪个合法？`a = i++` 合法吗？

<details><summary>答案</summary>

只有 `i++` 合法（后置），无前置 `++i`。`i++` 是独立语句，不能用在表达式或赋值右侧，所以 `a = i++` 非法。

</details>

---

**15.** 摄氏温度公式：`C = (F - 32) * 5 / 9`，以下代码为何得到错误结果？如何修复？

```go
c := (f - 32) * 5 / 9
```

<details><summary>答案</summary>

`5 / 9` 为整数除法，结果为 `0`，导致 `c` 永远为 `0`。修复：改为 `5.0 / 9` 或 `float64(5) / 9`。

</details>

---

**16.** `&&` 和 `||` 的短路规则是什么？

<details><summary>答案</summary>

- `&&`：遇到第一个 `false` 立即停止，不再求值后续表达式。
- `||`：遇到第一个 `true` 立即停止，不再求值后续表达式。

</details>

## 六、指针

**17.** 解释以下代码中每个符号的含义，并写出输出。

```go
x := 10
p := &x
fmt.Println(*p)
*p = 99
fmt.Println(x)
```

<details><summary>答案</summary>

- `&x`：取变量 `x` 的内存地址，赋给指针 `p`
- `*p`：解引用，读取 `p` 指向的值

输出：`10`，然后 `99`（通过指针修改了 `x`）。

</details>

## 八、输入输出

**22.** `fmt.Scanln` 和 `fmt.Scanf` 的区别是什么？

<details><summary>答案</summary>

- `fmt.Scanln`：每次读取一行（一个值），以换行结束。
- `fmt.Scanf`：按格式字符串读取多个值，如 `fmt.Scanf("%s %d", &name, &age)`。

两者都需要传变量地址（`&`）。

</details>

---

**23.** 以下代码有什么问题？

```go
var age int
fmt.Scanln(age)
```

<details><summary>答案</summary>

应传地址而非值：`fmt.Scanln(&age)`。不加 `&` 无法将输入写回变量。

</details>

## 九、位运算

**24.** 计算 `-3` 在 8 位有符号整数中的二进制补码表示。

<details><summary>答案</summary>

1. 原码：`10000011`（符号位1，数值位3）
2. 反码（取反数值位）：`11111100`
3. 补码（反码+1）：`11111101`

</details>

---

**25.** 以下三种位运算的规则各是什么？

| 运算 | 规则 |
|------|------|
| `&` | ? |
| `\|` | ? |
| `^` | ? |

<details><summary>答案</summary>

| 运算 | 规则 |
|------|------|
| `&` | 两位都为 1 才得 1，否则 0 |
| `\|` | 至少一位为 1 即得 1，否则 0 |
| `^` | 两位相同得 0，不同得 1 |

</details>

---

**26.** `-1 >> 2` 的结果是多少？为什么？

<details><summary>答案</summary>

`-1`。右移是算术移位，高位补符号位（1），`-1` 的补码全为 1，右移后仍然全为 1，结果仍为 `-1`。

</details>

## 十、流程控制

**27.** 以下 `if` 写法在 Go 中合法吗？

```go
if b = true; b {
    fmt.Println("yes")
}
```

<details><summary>答案</summary>

不合法。Go 要求 `if` 条件必须是布尔表达式，不能是赋值语句（`b = true` 是赋值）。合法写法：`if b := true; b { ... }`（短变量声明）。

</details>

---

**28.** Go 的 `switch` 和 C/Java 的 `switch` 有什么重要区别？

<details><summary>答案</summary>

Go `switch` 每个 `case` 执行后自动 break，不需要显式写 `break`，也不会穿透到下一个 case。

</details>

---

**29.** 写出判断闰年的完整布尔表达式（a 为年份）。

<details><summary>答案</summary>

```go
(a%4 == 0 && a%100 != 0) || a%400 == 0
```

</details>

