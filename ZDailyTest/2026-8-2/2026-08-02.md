## 一、函数递归

**1.** 以下代码输出什么？按出栈顺序写出打印结果。

```go
func Test(n int) {
    if n > 2 {
        n--
        Test(n)
    }
    fmt.Println("n =", n)
}
Test(4)
```

<details><summary>答案</summary>

```
n = 2
n = 2
n = 3
```

栈调用过程：Test(4) → Test(3) → Test(2)，最底层 Test(2) 先打印，然后逐层出栈打印。

</details>

**2.** 递归必须具备哪两个要素？缺一会怎样？

<details><summary>答案</summary>

1. **递归终止条件**（base case）—— 缺了会无限递归，最终栈溢出（stack overflow）
2. **递归公式**（递推关系）—— 缺了无法向终止条件逼近

</details>

**3.** 写出斐波那契数列第 n 项的递归公式和 Go 代码。

<details><summary>答案</summary>

公式：`F(1) = 1, F(2) = 1, F(n) = F(n-1) + F(n-2)`

```go
func Fib(n int) int {
    if n == 1 || n == 2 {
        return 1
    }
    return Fib(n-1) + Fib(n-2)
}
```

</details>

**5.** 猴子吃桃问题：每天吃一半加一个，第10天只剩1个。写出第1天桃子数的递归公式，以及求第1天桃子数的递归函数。

<details><summary>答案</summary>

公式：第 day 天桃子数 = (第 day+1 天桃子数 + 1) × 2

```go
func MonkeyPeach(day int) int {
    if day == 10 {
        return 1
    }
    return (MonkeyPeach(day+1) + 1) * 2
}
```

第1天调用 `MonkeyPeach(1)` 得到 1534。

</details>

## 二、函数类型与 type

**6.** 以下代码编译能通过吗？为什么？

```go
type mySum func(int, int) int

func Sum2(n1, n2 int) int { return n1 + n2 }
func Sum3(n1, n2, n3 int) int { return n1 + n2 + n3 }

func MyFunc(f mySum, a, b int) int { return f(a, b) }

func main() {
    a := Sum2
    b := Sum3
    fmt.Println(MyFunc(a, 1, 2))
    fmt.Println(MyFunc(b, 1, 2))
}
```

<details><summary>答案</summary>

`MyFunc(a, 1, 2)` 通过，因为 `Sum2` 的签名是 `func(int, int) int`，匹配 `mySum`。

`MyFunc(b, 1, 2)` **编译失败**，因为 `Sum3` 需要3个参数，签名是 `func(int, int, int) int`，不匹配 `mySum` 类型。

</details>

**7.** `type mySum func(int, int) int` 这行代码的作用是什么？

<details><summary>答案</summary>

定义了一个名为 `mySum` 的自定义类型，底层类型是 `func(int, int) int`。之后可以用 `mySum` 来简化函数参数的类型声明，使代码更清晰。

</details>

**8.** 以下代码输出什么？解释原理。

```go
c, d := 13, 24
Swap(&c, &d)
fmt.Printf("c:%d, d:%d\n", c, d)
```

其中 `Swap` 定义为：
```go
func Swap(n1, n2 *int) {
    var temp = *n1
    *n1 = *n2
    *n2 = temp
}
```

<details><summary>答案</summary>

输出：`c:24, d:13`

原理：传入的是 `c` 和 `d` 的地址（指针），函数内部通过 `*` 解引用直接操作原始变量，所以交换生效。

</details>

---

**9.** 如果把 `Swap` 的参数改为 `func Swap(n1, n2 int)`，只传值会怎样？

<details><summary>答案</summary>

函数内部交换的是 `n1` 和 `n2` 的副本，不影响外部的 `c` 和 `d`。输出仍然是 `c:13, d:24`。

</details>

## 三、递归深入理解

**10.** 递归调用时，Go 的调用栈是怎样的？"先入后出"是什么意思？

<details><summary>答案</summary>

每次递归调用会在栈顶压入一个新的函数帧，挂起当前层。最深层先执行完毕出栈，然后逐层返回。这就是"先入后出"——最先调用的函数最后执行完。

类比：叠盘子，最后放上去的最先拿下来。

</details>

**11.** 递归和循环相比，各有什么优缺点？

<details><summary>答案</summary>

| | 递归 | 循环 |
|---|---|---|
| 优点 | 代码简洁，天然适合树/图遍历、分治问题 | 效率高，无栈溢出风险 |
| 缺点 | 每次调用有额外开销，层数过深可能栈溢出 | 复杂问题代码不直观 |

</details>

**12.** 以下代码中 `func sum(n1, n2 float32) float32`，调用 `sum(1, 2)` 时，参数 1 和 2 的类型是什么？编译器做了什么？

<details><summary>答案</summary>

因为这里在函数内的传参是无参数类型数据，所以编译器会自己隐式转换数据类型

1 和 2 是整数字面量，但函数参数声明为 `float32`。编译器会自动将整数常量隐式转换为 `float32`，不会损失精度，也不需要手动写 `float32(1)`。

但注意：如果是变量（如 `var n int = 1`），则必须显式转换。

</details>
