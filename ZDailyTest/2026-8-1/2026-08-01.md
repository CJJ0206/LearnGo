## 一、for 循环

**1.** 写出 Go 中 for 的三种语法形式（框架即可，不用填逻辑）。

<details><summary>答案</summary>

```go
// 三段式
for i := 0; i < 10; i++ { }

// 条件式（相当于 while）
for i < 10 { }

// 死循环，配合 break 退出
for { }
```

</details>

---

**2.** for 初始化语句中用 `:=` 声明的变量，循环结束后还能访问吗？

<details><summary>答案</summary>

不能。`:=` 在 for 初始化里声明的变量作用域仅限循环体内，循环外访问会编译报错。

</details>

---

**3.** 用死循环 + break 打印 1 到 10。

<details><summary>答案</summary>

```go
i := 1
for {
    if i > 10 {
        break
    }
    fmt.Println(i)
    i++
}
```

</details>

**4.** 以下两种遍历字符串的方式，哪种对中文字符更友好？原因是什么？

```go
// A
for i := 0; i < len(str); i++ { fmt.Printf("%c", str[i]) }

// B
for _, v := range str { fmt.Printf("%c", v) }
```

<details><summary>答案</summary>

**B 更友好。** A 按字节遍历，中文占 3 字节会截断乱码；B 按 rune（int32）遍历，每次得到完整 Unicode 字符。

</details>

---

**5.** for-range 遍历字符串时，value 的类型是什么？

<details><summary>答案</summary>

`rune`（`int32`），一个完整的 Unicode 码点。

</details>

**6.** 用 for 分别模拟 while（先判断）和 do-while（先执行），打印 1 到 5。

<details><summary>答案</summary>

```go
// while
i := 1
for i <= 5 { fmt.Println(i); i++ }

// do-while
i := 1
for {
    fmt.Println(i)
    i++
    if i > 5 { break }
}
```

</details>

**7.** 求 1~100 中所有能被 9 整除的数之和，写出步长直接设为 9 的优化版本。

<details><summary>答案</summary>

```go
sum := 0
for i := 9; i <= 100; i += 9 {
    sum += i
}
```

比 `if i%9==0` 效率更高，意图更清晰。

</details>

**8.** 写出九九乘法表的核心嵌套循环（外层行，内层列）。

<details><summary>答案</summary>

```go
for i := 1; i <= 9; i++ {
    for j := 1; j <= i; j++ {
        fmt.Printf("%d x %d = %d \t", j, i, i*j)
    }
    fmt.Println()
}
```

内层上限是 `j <= i`，保证每行只打到对角线位置。

</details>

## 二、break 与 continue

**9.** break 和 continue 的区别是什么？

<details><summary>答案</summary>

- `break`：立即退出当前循环，不再执行后续迭代。
- `continue`：跳过本次迭代的剩余语句，直接进入下一次循环。

</details>

---

**10.** 以下代码输出什么？

```go
for i := 1; i <= 5; i++ {
    if i == 3 { continue }
    fmt.Print(i, " ")
}
```

<details><summary>答案</summary>

`1 2 4 5`（跳过了 3）

</details>

---

**11.** 标签（label）写在哪里？语法是什么？有什么用？

<details><summary>答案</summary>

标签写在目标 for 循环**正上方**，格式为 `标签名:`（冒号结尾）。用于在嵌套循环中，让 break/continue 直接作用于指定的外层循环。

```go
OuterLoop:
    for i := 0; i < 3; i++ {
        for j := 0; j < 3; j++ {
            if j == 1 { break OuterLoop }
        }
    }
```

</details>

---

**12.** 以下代码输出什么？

```go
here:
    for i := 0; i < 2; i++ {
        for j := 1; j < 4; j++ {
            if j == 2 { continue here }
            fmt.Printf("i=%d,j=%d ", i, j)
        }
    }
```

<details><summary>答案</summary>

`i=0,j=1  i=1,j=1`

`continue here` 在 j==2 时跳回外层循环下一次迭代，j=3 永远不会被执行。

</details>

## 三、switch fallthrough

**13.** Go switch 的默认行为是什么？`fallthrough` 做什么？

<details><summary>答案</summary>

Go switch 每个 case 执行后**自动 break**，不穿透。`fallthrough` 强制执行紧接着的**下一个 case 的语句体**，且只穿透一层。

</details>

---

**14.** 以下代码输出什么？

```go
i := 10
switch i {
case 10:
    fmt.Println("10")
    fallthrough
case 20:
    fmt.Println("20")
case 30:
    fmt.Println("30")
}
```

<details><summary>答案</summary>

```
10
20
```

匹配 case 10，`fallthrough` 穿透到 case 20 直接执行，case 30 不执行。

</details>

---

**15.** 要让 case 10 连续穿透到 case 30，需要怎么写？

<details><summary>答案</summary>

在 case 20 里再加一个 `fallthrough`：

```go
case 10:
    fmt.Println("10")
    fallthrough
case 20:
    fmt.Println("20")
    fallthrough
case 30:
    fmt.Println("30")
```

</details>

**17.** 以下函数定义有什么错误？

```go
func add(a, b) int {
    return a + b
}
```

<details><summary>答案</summary>

参数缺少类型。正确写法：

```go
func add(a int, b int) int { return a + b }
// 或同类型简写
func add(a, b int) int { return a + b }
```

</details>

**18.** 写一个 `calculate` 函数，接收两个 `float64` 和一个运算符 `byte`，用 switch 实现四则运算并返回结果。

<details><summary>答案</summary>

```go
func calculate(a, b float64, op byte) float64 {
    var result float64
    switch op {
    case '+': result = a + b
    case '-': result = a - b
    case '*': result = a * b
    case '/': result = a / b
    default:  fmt.Println("操作符未收录")
    }
    return result
}
```

</details>

**19.** `rand.Intn(100) + 1` 生成的随机数范围是多少？

<details><summary>答案</summary>

`rand.Intn(100)` 生成 `[0, 100)` 即 0~99，`+1` 后范围为 `1~100`。

</details>

**20.** for-range 不需要索引时怎么写？

<details><summary>答案</summary>

用 `_` 忽略索引：`for _, value := range str { }`

</details>

**21.** Go 有 while 和 do-while 关键字吗？

<details><summary>答案</summary>

没有，统一用 `for` 模拟：while → `for 条件 {}`，do-while → `for { 执行; if 退出条件 { break } }`

</details>

**22.** 嵌套循环建议最多几层？

<details><summary>答案</summary>

不超过 **3 层**，通常控制在 2 层，层数过深可读性极差。

</details>

**23.** 找出以下登录判断的 bug：

```go
} else if name == realName || code == realCode {
    fmt.Println("登录成功")
}
```

<details><summary>答案</summary>

`||` 应改为 `&&`。用 `||` 意味着用户名或密码**任意一个**正确就能登录，存在安全漏洞。

</details>

**24.** 以下代码实现了什么功能？`continue` 在这里的作用是什么？

```go
for i := 1; i <= 100; i++ {
    if i%2 == 0 { continue }
    fmt.Print(i)
}
```

<details><summary>答案</summary>

打印 1~100 的所有奇数。`continue` 在 i 为偶数时跳过本次迭代（不执行 Print），直接进入下一轮。

</details>

**25.** 以下代码在输入 0 时发生什么？

```go
for i := 1; i <= 100; i++ {
    fmt.Scan(&num)
    if num > 0 { countPo++; continue }
    else if num < 0 { countNe++; continue }
    else { break }
}
fmt.Printf("正数:%d 负数:%d", countPo, countNe)
```

<details><summary>答案</summary>

输入 0 触发 `break`，循环立即终止，不再接收输入，直接跳到最后的统计输出。

</details>
