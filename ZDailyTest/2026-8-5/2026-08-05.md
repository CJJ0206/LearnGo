## 一、自定义类型

**1.** `type ExecStatus string` 这行代码做了什么？`ExecStatus` 和 `string` 是完全相同的类型吗？

<details><summary>答案</summary>

定义了一个名为 `ExecStatus` 的新类型，底层类型是 `string`。

**它们不是相同的类型。** Go 把它们视为两种不同的类型，不能直接互相赋值（除非显式转换）。这是 Go 类型安全的关键设计。

```go
type ExecStatus string
var s string = "idle"
var e ExecStatus = s  // ❌ 编译错误：cannot use s as ExecStatus
```

</details>

---

**2.** 自定义类型相比直接用 `string` 有什么优势？列出至少 3 点。

<details><summary>答案</summary>

1. **类型安全**：防止误传无意义的字符串值（如把 `"running"` 误传给需要状态参数的函数）
2. **可绑定方法**：普通 `string` 不能绑定方法，自定义类型可以
3. **代码可读性**：`ExecStatus` 比 `string` 语义更清晰，一眼就知道是执行状态
4. **枚举约束**：配合常量定义一组枚举值，限制取值范围

</details>

---

**3.** 以下代码能编译通过吗？为什么？

```go
type ExecStatus string
const (
    StatusIdle    ExecStatus = "idle"
    StatusRunning ExecStatus = "running"
)

func UpdateStatus(id string, status ExecStatus) { ... }

UpdateStatus("A", "running")  // ← 这行
```

<details><summary>答案</summary>

**不能。** `"running"` 是未类型化的字符串常量，虽然底层是 `string`，但 `ExecStatus` 是独立的自定义类型，Go 不会自动类型转换。

编译器报错：`cannot use "running" (untyped string constant) as ExecStatus value`

正确写法：`UpdateStatus("A", StatusRunning)`

</details>

## 二、方法绑定

**4.** 以下代码中 `(s ExecStatus)` 是什么？它叫什么？

```go
func (s ExecStatus) ToChinese() string {
    switch s {
    case StatusIdle:    return "空闲中"
    case StatusRunning: return "运行中"
    }
    return "未知"
}
```

<details><summary>答案</summary>

`(s ExecStatus)` 是**接收者（receiver）**，它让 `ToChinese()` 方法绑定到 `ExecStatus` 类型上。

调用方式：`StatusRunning.ToChinese()` → `"运行中"`。

这类似于其他语言中"给类添加方法"，但 Go 是通过接收者实现的。

</details>

---

**5.** 值接收者和指针接收者有什么区别？什么时候用指针接收者？

<details><summary>答案</summary>

| 值接收者 `(s T)` | 指针接收者 `(s *T)` |
|---|---|
| 操作的是副本 | 操作的是原始值 |
| 不能修改原始值 | 可以修改原始值 |
| 调用时自动取副本 | 调用时传地址 |

**指针接收者适用场景：**
- 需要修改接收者的值
- 接收者是大结构体，避免拷贝开销
- 保持一致性（一个类型的所有方法最好统一用同一种接收者）

</details>

## 三、枚举常量

**6.** 以下代码中 `iota` 是什么？写出各行常量的值。

```go
const (
    A = iota  // ?
    B         // ?
    C         // ?
)
```

<details><summary>答案</summary>

`iota` 是 Go 的**常量计数器**，在 `const` 块中从 0 开始，每行递增 1。

```
A = 0
B = 1
C = 2
```

如果省略赋值表达式，则默认沿用上一行的表达式。

</details>

---

**7.** 在 Go 中实现枚举有几种方式？各有什么优缺点？

<details><summary>答案</summary>

**方式一：iota 整数枚举**
```go
const ( StatusIdle = iota; StatusRunning; StatusFailed )
```
优点：简洁，可以比较大小。缺点：打印出来是数字，可读性差。

**方式二：自定义类型 + 字符串常量（推荐）**
```go
type ExecStatus string
const ( StatusIdle ExecStatus = "idle"; ... )
```
优点：打印友好，类型安全，可绑定方法。缺点：略多代码。

</details>

## 四、综合练习

**8.** 完整实现一个 `DayType` 类型：底层 `string`，定义工作日/周末两个枚举常量，绑定一个方法返回该天是否要上班。

<details><summary>答案</summary>

```go
type DayType string

const (
    Weekday DayType = "weekday"
    Weekend DayType = "weekend"
)

func (d DayType) IsWorkDay() bool {
    return d == Weekday
}

// 使用
Weekday.IsWorkDay()  // true
Weekend.IsWorkDay()  // false
```

</details>

**9.** 以下代码有什么问题？

```go
type Age int
func (a Age) Double() int {
    return int(a) * 2
}
```

<details><summary>答案</summary>

没有语法问题，但 `Double()` 返回的是 `int` 而不是 `Age`，丢失了类型信息。如果需要保持类型安全，应该返回 `Age`：

```go
func (a Age) Double() Age {
    return a * 2
}
```

</details>
