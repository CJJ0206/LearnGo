## 一、init 函数

**1.** Go 程序中全局变量、`init()` 函数、`main()` 函数的执行顺序是什么？

<details><summary>答案</summary>

**全局变量初始化 → init() → main()**

验证代码：
```go
var age = test()  // 1. 最先执行
func test() int { fmt.Println("test()"); return 23 }
func init() { fmt.Println("init()") }  // 2. 其次
func main() { fmt.Println("main()") }  // 3. 最后
```

</details>

---

**2.** 一个包中可以有多个 `init()` 函数吗？一个文件中呢？

<details><summary>答案</summary>

可以。一个包中可以有多个 `init()`，一个文件中也可以有多个 `init()`。Go 编译器不会报错，同一文件内按定义顺序执行，同一包内按文件名排序后执行。

</details>

**3.** 以下 init 函数中，`switch runtime.GOOS` 的作用是什么？`runtime.GOOS` 在 Windows 上返回什么？

```go
func init() {
    switch runtime.GOOS {
    case "darwin":  OSName = "macOS"
    case "linux":   OSName = "Linux"
    case "windows": OSName = "Windows"
    }
}
```

<details><summary>答案</summary>

`runtime.GOOS` 返回当前操作系统的标识字符串。在 Windows 上返回 `"windows"`，在 macOS 上返回 `"darwin"`（苹果系统的内核名），在 Linux 上返回 `"linux"`。

这段代码根据运行环境自动选择配置，是实现跨平台兼容的常见模式。

</details>

---

**4.** `:=` 能写在函数外部（包级别）吗？为什么？

<details><summary>答案</summary>

**不能。** `:=` 是短变量声明，只能在函数体内使用。包级别的变量声明必须用 `var` 关键字：

```go
// ✅ 正确
var a int = 55

// ❌ 错误
a := 55  // 编译报错
```

</details>

## 二、匿名函数

**5.** 匿名函数的两种调用方式分别是什么？写出示例。

<details><summary>答案</summary>

**方式一：定义时立即调用**
```go
res := func(n1, n2 int) int {
    return n1 + n2
}(10, 20)  // 尾部加 () 立即执行
```

**方式二：赋值给变量后调用**
```go
a := func(n1, n2 int) int {
    return n1 - n2
}
res := a(10, 20)  // 通过变量名调用
```

</details>

---

**6.** 匿名函数赋给全局变量后，可以在其他包中使用吗？规则是什么？

<details><summary>答案</summary>

取决于**首字母大小写**：

```go
var (
    Fun3 = func(n1, n2 int) int { return n1 * n2 }  // ✅ 大写开头，导出，跨包可用
    fun4 = func(n1, n2 int) int { return n1 + n2 }  // ❌ 小写开头，仅本包可用
)
```

</details>

---

**7.** 匿名函数和普通函数最大的区别是什么？

<details><summary>答案</summary>

匿名函数没有函数名，不能像普通函数那样在包级别独立定义后被其他文件直接引用。它的优势在于即用即定义、可以捕获外部变量形成闭包。

</details>

## 三、字符串常用函数

**8.** `len("hello北京")` 返回多少？为什么不是 7？

<details><summary>答案</summary>

返回 **11**。`len()` 统计的是**字节数**：5 个英文字母各占 1 字节（共 5），2 个中文字各占 3 字节（共 6），总计 11 字节。

</details>

---

**9.** 如何正确遍历含中文的字符串，让每个中文字符正常输出？

<details><summary>答案</summary>

使用 `for-range`，它按 `rune`（Unicode码点）遍历，能正确处理中文：

```go
str := "hello北京"
for _, v := range str {
    fmt.Printf("%c", v)  // 每个字符都正确
}
```

或先转为 `[]rune` 再遍历：
```go
r := []rune(str)
for _, v := range r {
    fmt.Printf("%c", v)
}
```

</details>

**10.** `strconv.Atoi("123")` 和 `strconv.Atoi("abc")` 分别返回什么？为什么不 panic？

<details><summary>答案</summary>

- `Atoi("123")` → `(123, nil)`
- `Atoi("abc")` → `(0, error)`

Go 的设计哲学是**不 panic 而是返回 error**，让调用者自己决定如何处理错误。`Atoi` 返回 `(int, error)`，不会 panic。

</details>

**12.** `[]byte("Hello")` 和 `string([]byte{97, 98, 99})` 分别输出什么？

<details><summary>答案</summary>

- `[]byte("Hello")` → `[72 101 108 108 111]`（对应 H e l l o 的 ASCII 码）
- `string([]byte{97, 98, 99})` → `"abc"`（97='a', 98='b', 99='c'）

</details>

## 四、闭包（上）

**13.** 闭包 = 什么 + 什么？用一句话概括。

<details><summary>答案</summary>

**闭包 = 匿名函数 + 它引用的外部环境变量**

匿名函数"绑架"了外部变量，即使外部函数已经返回，这些变量也不会被回收。

</details>

---

**14.** 以下代码三次调用分别输出什么？

```go
f := AddUpper()  // AddUpper 返回 func(int) (int, string)
fmt.Println(f(1))
fmt.Println(f(2))
fmt.Println(f(3))
```

其中 `AddUpper` 内部 `var n int = 10`，返回的函数执行 `n += x`。

<details><summary>答案</summary>

```
11 hello1
13 hello12
16 hello123
```

`n` 的值被闭包捕获，每次调用都在上一次的基础上累加。`n` 不会在 `AddUpper()` 返回后被回收。

</details>

---

**15.** 为什么闭包中的 `n` 不会在 `AddUpper()` 返回后被回收？

<details><summary>答案</summary>

Go 编译器的**逃逸分析**发现 `n` 被返回的匿名函数引用，所以将 `n` 分配到堆上而不是栈上。只要闭包还存在，`n` 就不会被 GC 回收。这就是"变量逃逸"。

</details>
