## 一、new 函数

**1.** `new(int)` 做了什么？返回什么类型？

<details><summary>答案</summary>

1. 分配一块内存，大小刚好存放一个 `int`
2. 将该内存**清零**（初始化为零值 `0`）
3. 返回这块内存的**指针**（类型为 `*int`）

```go
num := new(int)      // num 是 *int 类型
fmt.Println(*num)    // 0（零值）
*num = 100           // 通过指针赋值
```

</details>

---

**2.** `new(T)` 返回的是 `*T`（指针），而不是 `T` 本身。这句话对吗？为什么这样设计？

<details><summary>答案</summary>

**对的。** `new` 的设计理念是：在堆上分配一块清零的内存，把地址给你，由你自己决定怎么用。返回指针意味着你可以通过解引用修改这块内存，也方便传递给其他函数。

</details>

---

**3.** 以下代码输出什么？

```go
num1 := 100
fmt.Printf("num1类型=%T, 值=%v, 地址=%v\n", num1, num1, &num1)

num2 := new(int)
fmt.Printf("num2类型=%T, 值=%v, 地址=%v, 指向值=%v\n", num2, num2, &num2, *num2)
```

<details><summary>答案</summary>

```
num1类型=int, 值=100, 地址=0x...
num2类型=*int, 值=0x...（指向的地址）, 地址=0x...（num2自己的地址）, 指向值=0
```

注意区分：
- `num2`（值）：存的是指向的那块内存地址
- `&num2`：num2 这个指针变量自己的地址
- `*num2`：num2 指向的那块内存中的值（初始为 0）

</details>

---

**4.** 用 `new` 分配一个结构体，和用 `&StructName{}` 有什么区别？

<details><summary>答案</summary>

两种方式等价，都返回 `*StructName` 并分配了零值初始化的内存：

```go
type Person struct {
    Name string
    Age  int
}

p1 := new(Person)      // 返回 *Person，字段为零值
p2 := &Person{}         // 同上，等价

p2 := &Person{Name: "Tom"}  // ✅ 可以在初始化时赋值
p1 := new(Person)           // ❌ 不能直接赋值，需要后续 p1.Name = "Tom"
```

`&StructName{...}` 更灵活，可以同时初始化字段，所以更常用。

</details>

## 二、make 函数

**5.** `make` 只能用于哪三种类型？为什么这些类型不能用 `new`？

<details><summary>答案</summary>

`make` 只能用于 **slice、map、channel** 三种类型。

这三种类型在 Go 底层是复杂的结构体（包含指针、长度、容量等元数据），`new` 只是清零内存，不会初始化这些内部结构，导致它们处于"瘫痪"状态，一用就 panic。`make` 则完成了底层结构的挂载和初始化，返回后立刻可用。

</details>

---

**6.** 以下代码有什么问题？

```go
var m map[string]int  // A
m["key"] = 1          // B

m2 := new(map[string]int)  // C
(*m2)["key"] = 1           // D
```

<details><summary>答案</summary>

A 声明了 nil map，B 向 nil map 写数据会 **panic**（`assignment to entry in nil map`）。

C 用 `new` 分配了 `*map[string]int` 但底层结构未初始化，D 同样会 **panic**。

正确写法：
```go
m := make(map[string]int)
m["key"] = 1  // ✅
```

</details>

**7.** 完成以下对比表格：

| 特性 | new | make |
|------|-----|------|
| 适用类型 | ? | ? |
| 返回值 | ? | ? |
| 内存初始化 | ? | ? |
| 返回后能否直接使用 | ? | ? |

<details><summary>答案</summary>

| 特性 | new | make |
|------|-----|------|
| 适用类型 | **所有类型** | **仅 slice/map/channel** |
| 返回值 | `*T`（指针） | `T`（类型本身，非指针） |
| 内存初始化 | 清零（零值） | 清零 + 内部结构初始化 |
| 返回后能否直接使用 | 可以（但 slice/map/channel 不行） | 可以直接使用 |

</details>

## 三、时间相关操作

**8.** Go 中解析时间的"魔法参考时间"是什么？为什么用它？

```go
time.Parse("2006-01-02", "2026-08-06")
```

<details><summary>答案</summary>

Go 的魔法参考时间是：`Mon Jan 2 15:04:05 MST 2006`，即 `2006-01-02 15:04:05`。

格式字符串中的数字有确定的含义：
- `2006` = 年，`01` = 月，`02` = 日
- `15` = 时（24小时制），`04` = 分，`05` = 秒

这个时间是 `1 2 3 4 5 6 7`（美国日期格式），Go 设计者用它作为"化石"标识，让开发者一看就知道每个数字代表什么时间单位。

</details>

---

**9.** 如何计算两个日期之间相差的天数？

```go
start, _ := time.Parse("2006-01-02", "1990-01-01")
end, _ := time.Parse("2006-01-02", "2026-08-06")
```

<details><summary>答案</summary>

```go
diff := end.Sub(start)            // 得到 Duration
totalDays := int(diff.Hours() / 24)  // 转为天数
```

`Sub` 方法返回 `time.Duration`，通过 `Hours()` 转为小时再除以 24 得到天数。

</details>

---

**10.** `time.Now()` 返回什么类型？如何获取当前时间的年、月、日？

<details><summary>答案</summary>

返回 `time.Time` 类型。

```go
now := time.Now()
year := now.Year()    // 2026
month := now.Month()  // August
day := now.Day()      // 6
```

</details>
